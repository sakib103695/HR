# HR — Next.js Fullstack Starter

This repository contains a minimal Next.js fullstack application with a simple API route and a frontend that consumes it.

Getting started:

1. Install dependencies

```bash
npm install
```

2. Run dev server

```bash
npm run dev
```

Open http://localhost:3000

To push changes to GitHub, ensure you have permission to push to the remote repo and run:

```bash
git remote add origin https://github.com/sakib103695/HR.git
git branch -M main
git push -u origin main
```
